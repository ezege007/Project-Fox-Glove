# Checkpoint Platform-Authoring Package (HTML)

This package contains 25 separately configurable checkpoint questions:

- Day 2 Baseline: B1–B10
- Day 5 Final: F1–F15

Every question now includes:
- task;
- starter code;
- allowed keywords/constructs;
- restrictions/forbidden constructs;
- visible sample tests;
- **private hidden sample tests**.

The checkpoint allow/restrict rules and hidden cases were added as platform-authoring controls aligned to each existing question. Hidden cases focus on boundary conditions and anti-hard-coding coverage.

**Never expose the hidden-sample section in the candidate-facing interface.**
