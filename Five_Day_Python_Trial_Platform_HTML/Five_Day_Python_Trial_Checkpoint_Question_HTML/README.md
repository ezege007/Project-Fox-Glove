# Platform-Ready Checkpoint Question HTML

This package contains each checkpoint question as a separate learner-facing HTML fragment.

## Day 2 Baseline
- B1 through B10
- 10 separate files
- B7–B10 are identified as stretch questions

## Day 5 Final
- F1 through F15
- 15 separate files

Each question file contains:
- question ID and title;
- task instructions;
- starter code;
- published sample checks;
- a short submission reminder.

Private hidden tests, solutions, answer keys, and assessor-only notes are intentionally excluded.
