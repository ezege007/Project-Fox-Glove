# Drill Platform-Authoring Package (HTML)

This package contains all 39 coding drills.

Every drill contains:
- instructions;
- starter/default code;
- allowed constructs;
- restrictions/forbidden strings;
- visible sample tests;
- **private hidden sample tests**.

The hidden samples come from the existing private drill authoring bank.

**Do not upload/render the hidden-sample section as learner-facing content.**
Use it only to configure private test cases in the platform.
