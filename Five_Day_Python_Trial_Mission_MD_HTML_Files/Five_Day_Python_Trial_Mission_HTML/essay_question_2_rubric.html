AI Grading Rubric — Easy Question 2

Goal: Check basic prompt/context and privacy awareness. Accept equivalent wording.

Useful information can include any two of:

  • the goal or what the function should do;
  • the relevant code snippet;
  • the expected result;
  • the actual result or error message;
  • a relevant failing input;
  • a constraint such as “do not change the function signature”;
  • the kind of help wanted, such as an explanation before a corrected version.

Information that should not be shared can include: passwords, API keys, access tokens, private keys, confidential customer information, private repository secrets, or unnecessary personal data.

  • Full credit: Gives at least two appropriate pieces of useful context and at least one appropriate sensitive item that should not be shared.
  • Partial credit: Gives only one correct useful-context item, or gives useful context but no valid privacy example, or gives a valid privacy example with only one useful-context item.
  • No credit: Gives unrelated information, recommends sharing secrets, or provides no meaningful response.

Do not penalize: short answers, bullet points, simple language, or minor grammar errors.
