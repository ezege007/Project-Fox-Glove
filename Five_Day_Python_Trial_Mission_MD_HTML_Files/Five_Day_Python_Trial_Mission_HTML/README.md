# Five-Day Python Trial — Mission Files (HTML)

This package contains three platform-ready mission units:

1. Day 2 Individual Mission — Personal Budget Helper
2. Day 3 Team Mission — Event Budget Helper, Part 1
3. Day 4 Team Mission — Event Budget Helper, Part 2

The Day 3 and Day 4 files split the shared team mission across the platform's day-based course structure.
